# Canonical Home: `apps/local-assistant`

This is now the canonical home of the Python local Antigone runtime.

It currently contains:

- `app/` for the Streamlit dashboard entrypoint
- `src/` for ingest, analysis, state, interaction, and visualization code
- `requirements.txt`
- `requirements-ml.txt`

Compatibility wrappers still exist at repo root so existing commands continue to work while the rest of the repository catches up.
